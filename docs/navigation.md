# Навигация VPS Manager

Главное меню разделяет установку, управление, проверку и обновление. Номера действуют только внутри текущего раздела: путь в заголовке помогает понять, где вы находитесь. `0` — назад; в главном меню `0` — выход. Неизвестный ввод и конец ввода не запускают действие.

## Установка

Пункт **1. Универсальная установка VPS** выполняет пакеты, SSH, UFW, базовый сетевой sysctl (BBR/fq, буферы, conntrack), автообновления, fail2ban и CrowdSec с Firewall Bouncer, затем AS-списки INPUT, Spamhaus/FireHOL INPUT, TCP C2 OUTPUT DROP и UDP Spamhaus OUTPUT DROP. Он использует текущее ядро; DNS, XanMod, Anti-DDoS, Docker и Remnanode устанавливаются отдельно. Автоматические баны подписок не включаются. TCP C2 работает с IPv4-парами IP:порт, UDP — с сетями Spamhaus IPv4/IPv6 в исходном направлении соединения. Оба режима DROP включаются постоянно и восстанавливаются при загрузке. Перед первым включением UDP запрашиваются исключения (или явный NONE); существующие исключения сохраняются. Сначала показывается состав, затем требуется `yes`. Настройка SSH запрашивает публичный ключ в терминале и проверяет его через ssh-keygen. Enter допустим только при уже установленном валидном ключе, 0 отменяет шаг. Встроенных ключей администратора в скрипте нет. Ошибка пакетов, SSH или UFW останавливает сценарий с отчётом. Остальные ошибки дают незавершённый результат и рекомендацию повторить только неудачный шаг. Это начальная настройка VPS, а не безопасное обновление рабочей ноды.

Откройте «7. Отдельные компоненты», затем выберите один компонент. Экран перед переходом описывает область изменений. `1` открывает выбранную настройку, `0` отменяет переход. Для базовых задач сначала выберите пакеты, SSH, UFW, fail2ban или автообновления. Для пакетного запуска используйте пункт 1 главного меню.

Открытие настроек не означает, что компонент установлен: завершение и результат зависят от выбранного установщика. Наличие компонентов и граф зависимостей здесь не вычисляются. Повторный запуск существующих установщиков не гарантирует сохранение нестандартных настроек.

## Частые задачи

| Задача | Путь |
| --- | --- |
| Установить Remnanode | Установка → Remnanode |
| Установить Docker | Установка → Docker |
| Настроить SSH | Установка → База → SSH |
| Настроить DNS | Сеть и ресурсы → NextDNS |
| TCP C2 DROP | Защита → Anti-Abuse → 2 |
| UDP Spamhaus DROP | Защита → Anti-Abuse → 3 |
| Анализ подписок без автобана | Защита → Anti-Abuse → 6 |
| Проверить обновление Guard | Обновления → 1 |
| Обновить движок Guard | Обновления → 2 |
| Посмотреть состояние сервера | Проверить сервер → 1 |

В разделе UDP Spamhaus пункт 1 готовит базовый Spamhaus OUTPUT и UDP-расширение. Порядок установки зависимостей не требуется выбирать вручную. Установка создаёт Observe для новой конфигурации и сохраняет существующий режим; включение DROP остаётся отдельным пунктом.

UDP-меню: 1 — установить/подготовить; 2 — статус; 3 — включить DROP; 4 — отключить; 5 — исключения; 6 — оставить DROP после проверки доступа. Пункт 3 использует прежнее подтверждение и таймер автоотключения.

При ручном включении DROP используются подтверждения и защитные таймеры соответствующих модулей. Универсальная установка отдельно и явно включает постоянный TCP/UDP DROP без временного автоотключения. Журнал запуска менеджера продолжает записываться.

## Журнал установки CrowdSec

Каждый запуск установки сохраняет stdout и stderr в отдельный `/var/log/vps-setup-crowdsec.*.log` с правами 0600 и возвращает исходный код ошибки. Сводный журнал содержит путь к подробному. Работа агента без установленного Firewall Bouncer не означает завершение установки защиты.

Проверка Hub использует `cscli … inspect -o json` и поле `installed`. Обычный `inspect` в CrowdSec 1.4.x также запрашивает Prometheus-метрики, поэтому его код возврата не подходит для определения наличия коллекции. Установленные `tainted` коллекции сохраняются; неактивные `tainted` и неизвестное состояние требуют ручной проверки. Принудительная перезапись не применяется. Тот же способ используется для SSH-парсера.

Регрессия проверяется с реальным пакетом CrowdSec из Ubuntu 24.04 при остановленном агенте: обнаружение коллекций и SSH-парсера должно завершиться без изменения пакетных файлов.
