# Навигация VPS Manager

Главное меню разделяет установку, управление, проверку и обновление. Номера действуют только внутри текущего раздела: путь в заголовке помогает понять, где вы находитесь. `0` — назад; в главном меню `0` — выход. Неизвестный ввод и конец ввода не запускают действие.

## Установка

Откройте «1. Установить и настроить компоненты», затем выберите один компонент. Экран перед переходом описывает область изменений. `1` открывает выбранную настройку, `0` отменяет переход. Для базовых задач сначала выберите пакеты, SSH, UFW, fail2ban или автообновления. Пакетного запуска этих задач больше нет в обычном установочном меню.

Открытие настроек не означает, что компонент установлен: завершение и результат зависят от выбранного установщика. Наличие компонентов и граф зависимостей здесь не вычисляются. Повторный запуск существующих установщиков не гарантирует сохранение нестандартных настроек.

## Частые задачи

| Задача | Путь |
| --- | --- |
| Установить Remnanode | Установка → Remnanode |
| Установить Docker | Установка → Docker |
| Настроить SSH | Установка → База → SSH |
| Настроить DNS | Сеть и ресурсы → NextDNS |
| TCP C2 DROP | Защита → Anti-Abuse → 2 |
| UDP Spamhaus DROP | Защита → Anti-Abuse → 3 |
| Анализ подписок без автобана | Защита → Anti-Abuse → 6 |
| Проверить обновление Guard | Обновления → 1 |
| Обновить движок Guard | Обновления → 2 |
| Посмотреть состояние сервера | Проверить сервер → 1 |

DROP, исключения и защитные таймеры остаются в своих модулях. Изменение меню не включает и не отключает защиты. Журнал запуска менеджера продолжает записываться.
