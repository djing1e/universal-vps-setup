# VPS Inventory — Audit v0.1

Первый этап Safe Upgrade: только инвентаризация, без операций установки,
обновления, удаления, перезапуска, резервирования или отката. Основное меню
и пункт 00 не изменены.

Запуск из проверенного checkout (стандартная библиотека Python 3):

```bash
clear
python3 lib/vps_inventory.py audit
```

Результат — JSON в stdout. Сам Audit не создаёт отчёт на диске. Можно запускать
без root: недоступные проверки останутся unknown. Отсутствие инструмента не
доказывает отсутствие компонента. Каждая команда ограничена временем и объёмом
вывода. DNS, firewall, маршруты и systemd только читаются. nft-наборы целиком
не выводятся.

Docker опрашивается через фиксированный локальный сокет только если systemd
подтверждает активный docker.service. Удалённый DOCKER_HOST не используется.
Вывод контейнеров ограничен ID, именем, образом и состоянием: без команды,
переменных окружения, compose-файлов и inspect. Если Docker работает вне systemd,
проверка контейнеров остаётся unknown.

Совпадение SHA256 с manifest означает known_content, а не владение ресурсом.
Локальное изменение — custom_or_unknown, символическая ссылка/ошибка чтения —
unknown. Версия модуля и разрешение на update из хеша не выводятся. Автоматический
update всегда закрыт: update_gate=manual_review_required. Будущему planner нужны
версии, проверка владельца, зависимостей, backup и проверяемый rollback.

Снимок не атомарный и не является доказательством здоровья VPN. Вывод DNS,
маршрутов и интерфейсов может содержать внутреннюю топологию; проверяйте отчёт
перед публикацией. Никакие результаты не отправляются наружу.
